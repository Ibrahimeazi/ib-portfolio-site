# Ibrahim Bilau portfolio

The website presents the 18 supplied portfolio slides as a full-screen horizontal deck. Each slide is rendered directly from the source PDF at 1920 x 1080 so its original composition is preserved.

Scroll vertically with a mouse or trackpad to advance horizontally one slide at a time. Horizontal swiping, arrow keys, Page Up, Page Down, Space, Home, and End are also supported.

A subtle navigation cue introduces the left-swipe gesture, reduces to a slide count while browsing, and labels the Home and End states. Trackpad momentum and touch flicks are resolved to exactly one slide per gesture.
